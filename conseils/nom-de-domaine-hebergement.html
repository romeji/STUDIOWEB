Nom de domaine et hébergement : quelle différence ?

Pour publier un site, il faut une adresse facile à communiquer et un hébergement qui rende ses fichiers disponibles. Ces deux éléments sont liés, mais ne désignent pas la même chose.

Le nom de domaine est l’adresse du site

Un nom de domaine, comme monentreprise.fr, permet aux visiteurs de retrouver le site sans saisir l’adresse technique du serveur. Il se renouvelle périodiquement auprès d’un bureau d’enregistrement, appelé registrar. La disponibilité dépend du nom et de l’extension demandés au moment de la réservation.

Choisis un nom facile à prononcer, à écrire et à communiquer par téléphone. Vérifie qu’il ne prête pas à confusion avec une autre marque et garde la maîtrise de l’adresse. Dans l’offre JL Studio Web, le domaine standard est enregistré au nom du client selon les conditions prévues ; le récapitulatif de commande précise les modalités et éventuels suppléments.

L’hébergement conserve les fichiers du site

L’hébergement est le service qui stocke les pages, images et fichiers techniques et les transmet aux visiteurs. Un site peut changer d’hébergeur sans changer de nom de domaine, comme une entreprise peut changer de local sans changer d’adresse postale. L’hébergement est inclus dans l’abonnement JL Studio Web pendant la période prévue par la formule.

Le HTTPS sécurise la connexion

Le HTTPS chiffre les échanges entre le navigateur et le site, et s’affiche généralement avec un cadenas dans le navigateur. Il est devenu attendu pour les sites professionnels, en particulier lorsqu’ils comportent un formulaire. Le certificat correspondant est inclus dans l’accompagnement JL Studio Web décrit sur le site.

Que vérifier avant de souscrire ?

  • Qui est enregistré comme titulaire du domaine ?
  • Qui paie les renouvellements et à quelle fréquence ?
  • L’hébergement et le certificat HTTPS sont-ils compris ?
  • Comment récupérer le code de transfert si tu changes de prestataire ?
  • Que devient le site à la fin de l’abonnement ?
À retenir : le domaine est l’adresse, l’hébergement est le service qui rend le site accessible. Demande toujours qui contrôle le domaine et comment le transférer avant l’échéance de renouvellement.
